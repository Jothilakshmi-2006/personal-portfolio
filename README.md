# Personal Portfolio Website

## 📌 Project Overview

This is my personal portfolio website developed to showcase my profile, educational background, technical skills, projects, and contact information.

## 🎯 Project Objective

The main objective of this project is to create a professional online portfolio to present my web development skills and projects.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Home section with personal introduction
- About Me section
- Technical Skills section
- Projects showcase
- Contact information
- Attractive user interface
- Responsive design for different screen sizes

2. Open the project folder.
3. Open the `index.html` file in a web browser.
4. Explore the different sections of the website.
